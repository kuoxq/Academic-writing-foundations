# Academic Writing Foundations

## Purpose

Use this skill as a lightweight front-end for academic paper writing. Help the user move from a broad idea or messy draft to a clear research question, paper structure, argument map, and revision plan.

This skill is based on the writing competencies reflected in university library guidance such as Sacred Heart University Library's "Organizing Academic Research Papers" guide, but it should operate as a practical workflow rather than a summary of that page.

## Workflow

### 1. Diagnose the Stage

Identify the user's current stage:

- Broad topic with no research question
- Tentative research question but weak scope
- Outline needed
- Draft section needs structure
- Full draft needs revision
- Language polish needed after structure is stable

If the topic is vague, do not jump to a full outline. First narrow the topic into one or more answerable research questions.

### 2. Build the Foundation

For early-stage work, produce these items in order:

1. Topic scope: population/context, object of study, time/place, discipline, and key concepts
2. Research question: one main question and optional subquestions
3. Working thesis or central claim, if the paper type supports one
4. Rationale: why the issue matters academically
5. Evidence plan: what kinds of sources, data, theory, or cases are needed

Keep uncertainty visible. Label speculative claims as provisional.

### 3. Create the Paper Architecture

When the research question is clear, create a structured outline:

- Introduction: background, problem, gap, aim, contribution
- Literature review: organize by themes, debates, methods, theories, or chronology
- Methods or approach: explain how the question will be answered when relevant
- Analysis/body: arrange claims in a logical sequence
- Discussion: interpret significance, limitations, implications, and future work
- Conclusion: synthesize rather than repeat

Prefer section-level headings plus 1-2 sentence purpose notes for each section.

### 4. Convert Outline to Argument Map

For each major section or paragraph, use:

- Claim: what the paragraph argues
- Evidence: what supports it
- Analysis: how the evidence answers the research question
- Link: how the paragraph connects to the next move

If evidence is missing, mark it as "needs source" rather than inventing a citation.

### 5. Revise Drafts

When revising existing prose, prioritize:

1. Research question alignment
2. Section order and paragraph function
3. Claim-evidence-analysis balance
4. Transitions and signposting
5. Academic tone and precision
6. Grammar and surface polish

Do not merely improve sentences when the structure is weak. Explain the structural issue briefly, then provide a revised version.

## Handoffs to Existing Skills

Use this skill as the starting layer. Escalate or combine with existing skills when needed:

- Use `academic-research-suite` for deep research, literature discovery, systematic review, citation verification, full paper pipelines, peer review simulation, or experiment planning.
- Use `academic-phrasebank` when the argument and structure are already clear but the user needs more idiomatic academic English.
- Use `zotero` when the task requires searching the user's Zotero library, exporting BibTeX, or inserting citation keys.
- Use `Scite` or web verification when claims require current or source-grounded evidence.
- Use `documents` when the user needs a polished `.docx` artifact.

## Output Patterns

For beginner-facing help, prefer compact tables and staged outputs. Useful formats include:

- "Topic -> Research Question -> Working Thesis"
- "Outline with Section Purpose"
- "Argument Map"
- "Revision Diagnosis + Revised Passage"
- "Final Self-Check Checklist"
