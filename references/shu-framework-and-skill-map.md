# SHU-Inspired Writing Framework and Skill Map

## Core Skill Group

| Subskill | Function | Typical Output |
|---|---|---|
| Topic narrowing | Turn a broad interest into a feasible academic focus | Scope statement, keywords, boundaries |
| Research problem/question | Define what the paper asks and why it matters | Main RQ, subquestions, aim |
| Outline design | Arrange the paper's logic before drafting | Section outline with purpose notes |
| Introduction writing | Establish background, problem, gap, aim, and contribution | Introduction plan or draft |
| Literature organization | Synthesize sources by theme, debate, theory, method, or chronology | Literature review structure |
| Evidence-based argument | Connect claims to sources, data, theory, or cases | Claim-evidence-analysis map |
| Academic style | Use formal, precise, cautious, reader-oriented prose | Revised academic paragraphs |
| Discussion writing | Interpret findings, implications, limitations, and future work | Discussion plan or draft |
| Revision and self-check | Test coherence, alignment, source support, and tone | Revision checklist |

## Recommended Workflow

1. Topic -> scope statement
2. Scope statement -> research question
3. Research question -> working thesis or central purpose
4. Central purpose -> outline
5. Outline -> argument map
6. Argument map -> draft sections
7. Draft sections -> structural revision
8. Stable draft -> academic language polish
9. Final draft -> self-check and citation review

## Diagnostic Questions

Ask only the questions needed for the current stage:

- What is the broad topic, and what course, field, or journal context is it for?
- What specific population, case, text, event, platform, method, or theory is in scope?
- Is the paper expected to be argumentative, empirical, theoretical, reflective, or review-based?
- What sources or data are already available?
- What is the required length, format, citation style, and deadline?
- What claim or contribution should the reader remember?

## Comparison with Existing Skills

| Skill | Best For | Boundary |
|---|---|---|
| academic-writing-foundations | Beginner-to-intermediate paper planning: topic, RQ, outline, argument, introduction, discussion, revision checklist | Does not perform deep literature discovery or full citation verification by default |
| academic-research-suite | Deep research, literature review, systematic review, full research-to-paper workflow, peer review, integrity checks | More powerful but heavier; may be too much when the user only needs foundational writing structure |
| academic-phrasebank | Academic English phrasing, transitions, cautious claims, section-specific wording | Does not decide research design, paper logic, or evidence sufficiency |
| zotero | Local library search, BibTeX export, citation key insertion | Manages references, not writing architecture |
| Scite | Source-grounded research support and peer-reviewed evidence checks | Supports evidence validation, not full writing pedagogy |
| documents | Producing and editing polished Word-style documents | Handles document artifact quality, not research-paper reasoning |

## Routing Rule

Start here when the user's problem sounds like:

- "I do not know how to write this paper."
- "Help me turn this topic into a research question."
- "Can you make an outline?"
- "My introduction/literature review/discussion is messy."
- "Teach me how to organize an academic research paper."

Move to `academic-research-suite` when the user needs actual literature search, systematic synthesis, source verification, full-paper drafting, or review simulation.

Move to `academic-phrasebank` after structure and argument are stable and the main need is academic English expression.
